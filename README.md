# Nyx | Biblioteca de Novelas Indie

Nyx es una plataforma web minimalista, libre de algoritmos agresivos, diseñada para albergar y dar visibilidad a novelas e historias independientes.

## 🚀 Tecnologías utilizadas
* HTML5 Semántico
* CSS3 Puro (con anidamiento moderno y Flexbox)
* Fuentes globales vía Google Fonts (Montserrat & Open Sans)

## 📌 Estado del proyecto
Actualmente en desarrollo activo de la interfaz del catálogo principal y maquetación de componentes genéricos.
